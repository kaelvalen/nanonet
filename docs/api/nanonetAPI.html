NanoNet API (1.0.0)

Download OpenAPI specification:

NanoNet — Mikroservis İzleme ve Yönetim Platformu REST API dokümantasyonu.

Kimlik Doğrulama: Korumalı endpoint'ler JWT Bearer token gerektirir. Access token Authorization: Bearer <access_token> header'ı ile iletilir. Token süresi 15 dakikadır; /api/v1/auth/refresh ile yenilenebilir.

Base URL: http://localhost:8080

Versiyon: v1
