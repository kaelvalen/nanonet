# @nanonet/shared-types

Frontend ve mobile arasında paylaşılan TypeScript tipleri.

## Modüller

| Dosya | İçerik |
|-------|--------|
| `auth.ts` | Kullanıcı, token çifti |
| `service.ts` | Servis modeli |
| `metrics.ts` | Metrik noktaları |
| `alerts.ts` | Uyarı tipleri |
| `logs.ts` | Log girişleri |
| `ai.ts` | AI insight / chat |

## Kullanım

```typescript
import type { Service } from "@nanonet/shared-types";
```

Workspace kökünden `npm install` ile bağlanır.
